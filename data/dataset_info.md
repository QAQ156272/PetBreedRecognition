# 数据集说明

## Oxford-IIIT Pet Dataset

- **来源**: https://www.robots.ox.ac.uk/~vgg/data/pets/
- **内容**: 37 种猫狗品种，每类约 200 张图片
- **总数**: 约 7,400 张
- **标注**: 包含品种标签、头部 ROI 标注、像素级分割标注

## 数据预处理

1. 下载原始数据集并解压到 data/oxford_pet/
2. 按品种分文件夹组织（ImageFolder 格式）
3. 自动划分为训练集 (80%) 和验证集 (20%)
4. 应用数据增强：随机裁剪、水平翻转、旋转、颜色抖动
